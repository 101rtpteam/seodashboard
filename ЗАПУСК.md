# 101RTP SEO Dashboard — Инструкция по запуску

## Что нужно установить на компьютер

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — скачай и установи
- Python 3 (для одноразовой авторизации) — проверь: `python3 --version`

---

## Шаг 1 — Получи Google Search Console credentials

1. Зайди на [console.cloud.google.com](https://console.cloud.google.com)
2. Создай новый проект (или выбери существующий)
3. Слева: **APIs & Services → Library** → найди **Google Search Console API** → Enable
4. Слева: **APIs & Services → Credentials** → **+ Create Credentials → OAuth 2.0 Client ID**
5. Application type: **Desktop app** → Название: любое → Create
6. Нажми **Download JSON** → переименуй файл в `client_secret.json`
7. Положи файл в папку `credentials/` внутри проекта:
   ```
   101rtp-seo-dashboard/
   └── credentials/
       └── client_secret.json   ← сюда
   ```

> ⚠️ Если OAuth consent screen попросит добавить test users — добавь свой Gmail аккаунт.

---

## Шаг 2 — Авторизация (один раз)

Установи Python-зависимости для авторизации:

```bash
pip3 install google-api-python-client oauth2client httplib2
```

Запусти авторизацию:

```bash
python3 authorize_gsc.py
```

Откроется браузер → войди в Google → разреши доступ.

После успешной авторизации появится файл `credentials/authorizedcreds.dat`.  
Это токен — **не удаляй его**. Он нужен для работы дашборда.

---

## Шаг 3 — Запуск

```bash
docker-compose up --build
```

Первый раз займёт 3–5 минут (скачивает образы, собирает frontend).  
Последующие запуски: `docker-compose up` (без `--build`) — быстро.

Дашборд откроется по адресу: **[http://localhost:3000](http://localhost:3000)**

---

## Шаг 4 — Настройка в дашборде

1. Открой [http://localhost:3000/settings](http://localhost:3000/settings)
2. Вставь **OpenAI API Key** (формат `sk-proj-...`) → Save Settings
3. Нажми **Authorize Credentials** → должно появиться "Credentials are authorized"
4. В разделе **Sites Overview Selection** выбери сайты 101RTP (до 6 штук)
5. Save Settings

```bash
docker-compose down
```

## Обновление

```bash
docker-compose down
docker-compose up --build
```

---

## Структура папки credentials/

```
credentials/
├── client_secret.json       ← скачиваешь с Google Cloud Console (шаг 1)
├── authorizedcreds.dat      ← создаётся автоматически после authorize_gsc.py (шаг 2)
└── authorized_trends_token.json  ← только если используешь Google Trends (опционально)
```

> ⚠️ **Никогда не коммить папку `credentials/` в публичный репозиторий.** Она уже добавлена в `.gitignore`.

## Google Trends (опционально)

Это отдельная фича для анализа Trends vs GSC трафика.  
Требует отдельный OAuth client с scope `searchtrends`.  
Можно настроить позже — базовый дашборд работает без этого.

## Вопросы и проблемы

| Проблема | Решение |
|----------|---------|
| `docker: command not found` | Установи Docker Desktop |
| Браузер не открылся при авторизации | Скопируй ссылку из терминала вручную |
| "GSC service not initialized" | Убедись что `authorizedcreds.dat` есть в `credentials/` |
| Порт 3000 занят | Измени в docker-compose.yml: `"3001:3000"` |
| Порт 5001 занят | Измени в docker-compose.yml: `"5002:5001"` |
